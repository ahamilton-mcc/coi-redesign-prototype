# COI redesign prototype (internal, not final)

An internal design prototype for the COI sites' Trend Hunter-style redesign. It is **not a live site** and the content is sample content.

- Open `index.html` (or the GitHub Pages link) to start.
- Use the dark bar at the bottom of every page to switch **brand** (Student Section / Crime Hunter), turn **ads** on or off, jump between **pages** (home, category, article, About, author), and preview **Desktop / Tablet / Mobile**.
- `coi-core.css` and `coi.js` are the shared code used by every site. Each brand only supplies a small color and config file (`brand-*.css`, `brand-*.js`).
- Sample stories come from the public Student Section site; photos are loaded from there and are not stored in this repository.

Status: work in progress, shared for review only. Not for indexing or redistribution.
